# Reglas del Proyecto 3

Trabajar exclusivamente en esta carpeta. No modificar Proyecto 2 ni su historial o configuración.

Usar únicamente la cuenta GitHub icruzat1 que está vinculada a VS Code. No utilizar el conector GitHub de oficina, ni consultar sus repositorios o credenciales. Las operaciones remotas se realizan mediante la sesión personal de VS Code. No cambiar la configuración global de Git.

El usuario autorizó Docker Desktop para Apple Silicon y la creación de icruzat1/Proyecto3-Arqui privado. Confirmar otros cambios importantes y acciones externas que excedan esa autorización. Los acuerdos de licencia se presentan al usuario antes de aceptarlos.

Mantener docs/Cuaderno_Estudio_Defensa.md, docs/Cuaderno_Continuidad.md y docs/Checklist.md. Registrar resultados medidos, supuestos y pendientes de forma diferenciada.

No redactar prompts de Codex por adelantado. Conversar sobre cada tarea y redactar su prompt justo antes de ejecutarla cuando corresponda. Terminar las respuestas con una recomendación breve de potencia de pensamiento.

Conservar baseline/proyecto2 como referencia FPGA portable. Los cambios ASIC se desarrollarán por separado en rtl. Verificar latencias, reset y ciclos antes de las corridas físicas. No ejecutar el Makefile FPGA por defecto porque programa la placa.
